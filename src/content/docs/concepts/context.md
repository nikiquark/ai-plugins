---
title: "Контекст и /clear"
---

Качество ответов модели падает по мере заполнения контекстного окна, а автосжатие (`/compact` и автоматическое) теряет детали. Пайплайн решает это тремя способами.

1. **Основной диалог только координирует.** Объёмные задачи выполняют субагенты, в основной диалог попадают их краткие отчёты.
2. **Вся память — в файлах.** `.claude/state/pipeline.json` и `docs/` содержат всё, что нужно для продолжения работы ([Состояние и возобновление](state.md)).
3. **Хук предупреждает о заполнении.** [context-guard](../dev-core/context-guard.md) сообщает оркестратору, что контекст заполнен на 50%, 60% и далее.

## Чистые точки перезапуска

На ближайшей границе этапов оркестратор сохраняет состояние и предлагает:

> Выполните `/clear`, затем `/web-pipeline:<та же команда>`. Пайплайн продолжит с `<phase>`.

Чистые точки перезапуска:

- после GATE 1 (смысл и архитектура утверждены);
- после GATE 2 (дизайн выбран);
- между задачами в фазе D3;
- перед ревью D4.

`/clear` предпочтительнее `/compact`: всё важное уже записано в файлы, и сжатие только потеряет детали.

## Строка состояния

Claude Code не передаёт хукам процент заполнения контекста. Это число есть только во входных данных строки состояния. Поэтому context-guard читает кэш, который должна писать ваша строка состояния:

```text
${XDG_CACHE_HOME:-~/.cache}/claude-context/<session_id>
```

Файл содержит одно целое число — процент. Если кэша нет, хук молчит, а остальной пайплайн работает как обычно.

Минимальный скрипт `~/.claude/statusline.sh`:

```bash
#!/usr/bin/env bash
# Status line that also caches the context percentage for dev-core's context-guard hook.
input=$(cat)
pct=$(jq -r '.context_window.used_percentage // empty' <<<"$input")
sid=$(jq -r '.session_id // empty' <<<"$input")
model=$(jq -r '.model.display_name // ""' <<<"$input")

pct=${pct%.*}
if [[ -n $pct && -n $sid ]]; then
  cache=${XDG_CACHE_HOME:-$HOME/.cache}/claude-context
  mkdir -p "$cache" && printf '%s\n' "$pct" >"$cache/$sid"
fi

printf '%s%s' "$model" "${pct:+ · ${pct}%}"
```

Подключите его в `~/.claude/settings.json`:

```json
{
  "statusLine": { "type": "command", "command": "~/.claude/statusline.sh", "padding": 0 }
}
```

и сделайте исполняемым: `chmod +x ~/.claude/statusline.sh`. Если у вас уже есть своя строка состояния, добавьте в неё блок, который пишет кэш.

## Порог

Порог задаётся переменной окружения `CONTEXT_WARN_PCT` (по умолчанию `50`). Хук предупреждает один раз на каждую десятку процентов: 50, 60, 70… Если контекст опустится ниже порога (например, после `/clear`), счётчик сбрасывается.

```bash
CONTEXT_WARN_PCT=40 claude
```
