Готовит интервью с клиентами: скрипт по *The Mom Test*, привязанный к проверяемым гипотезам, скринер, каналы поиска респондентов с первыми сообщениями и нужное число интервью из порога гейта.

| | |
|---|---|
| Вызов | `/idea-pipeline:interview-kit [сегмент]` |
| Автовызов | Да, перед интервью по проблеме или решению |
| Кто работает | [customer-researcher](../agents/customer-researcher.md) в режиме interview-kit |
| Результат | `docs/idea/interviews/script-<segment>.md` |
| Исходник | `plugins/idea-pipeline/skills/interview-kit/SKILL.md` |

## Шаги

1. Нужны `docs/idea/customers.md` и `docs/idea/experiments.md`, иначе сначала [`new-idea`](new-idea.md).
2. **Сегмент**: из аргумента, иначе плацдарм из `strategy.md`.
3. **Эксперимент**: интервью-эксперимент текущей стадии и листья, которые он проверяет. Если такого нет, команда спрашивает, что проверять и какие пороги pass и kill. Эксперимент записывается в `experiments.md` до скрипта: пороги задаются заранее.
4. [customer-researcher](../agents/customer-researcher.md) пишет скрипт.
5. Вам дают путь, число интервью, каналы и три самых важных вопроса.

## Что в скрипте

- **Цель**: какие листья дерева проверяются и в какую метрику гейта это идёт.
- **Скринер**: кто подходит, кто нет. Друзья, фанаты и чужой сегмент отсекаются.
- **Где искать**: каналы из `customers.md` и короткое первое сообщение для каждого на языке рынка.
- **Вопросы**, 8–12, у каждого свой лист дерева: контекст → последний раз, когда случилась проблема → что делали и сколько это стоило → что пробовали раньше → просьба об обязательстве.
- Как звучит ответ «за» и «против» для каждого листа.
- Число интервью из порога B → C в `readiness.md`.

## Правила, по которым интервью считается доказательством

- Не рассказывать об идее, пока не закончились вопросы. Лучше не рассказывать совсем.
- Спрашивать о прошлом и конкретных случаях, а не о мнениях о будущем.
- Комплименты и «я бы купил» не считаются. Считаются обязательства: время, знакомство, пилот, предоплата.
- Каждое интервью в тот же день записывается через [`evidence`](evidence.md).
