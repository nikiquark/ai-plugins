# MCP Context7

[Context7](https://context7.com) отдаёт актуальную документацию и примеры кода библиотек. Модель знает API на момент обучения, а Context7 — текущие версии.

| | |
|---|---|
| Тип | HTTP MCP |
| URL | `https://mcp.context7.com/mcp` |
| Объявлен в | `plugins/dev-core/.mcp.json` |
| Кто использует | [`reuse-first`](skills/reuse-first.md), [architect](../web-pipeline/agents/architect.md), [backend-dev](../web-pipeline/agents/backend-dev.md) и все, кто выбирает или использует библиотеку |

## Инструменты

| Инструмент | Назначение |
|---|---|
| `resolve-library-id` | Найти идентификатор библиотеки по названию |
| `get-library-docs` | Получить документацию по идентификатору, при необходимости по теме |

Протокол [`reuse-first`](skills/reuse-first.md) требует сначала разрешить идентификатор, затем загрузить документацию, и только потом писать код на основе текущего API.

## Проверка

Выполните `/mcp` в сессии: сервер `context7` должен быть в списке и подключён. Если сеть недоступна, агенты продолжат работу по своим знаниям, но протокол reuse-first станет менее надёжным.
