# MCP Playwright

[Playwright MCP](https://github.com/microsoft/playwright-mcp) даёт агентам управляемый браузер: открыть страницу, кликнуть, заполнить форму, снять скриншот на нужной ширине.

| | |
|---|---|
| Тип | stdio MCP |
| Запуск | `npx -y @playwright/mcp@latest` |
| Объявлен в | `plugins/web-pipeline/.mcp.json` |
| Требования | Node.js с `npx`; при первом запуске может понадобиться скачать браузер |

## Кто использует

| Агент | Для чего |
|---|---|
| [designer](agents/designer.md) | Скриншоты концептов на 375 и 1440 px для самопроверки |
| [frontend-dev](agents/frontend-dev.md) | Скриншоты на 375, 768 и 1440 px и сравнение с `docs/design.md` до отчёта |
| [design-critic](agents/design-critic.md) | Скриншоты всех затронутых страниц, hover, focus, проход с клавиатуры |

Все три агента продолжают работу и без Playwright: они сообщают, что инструментов нет, и проверяют только по коду. Качество визуального ревью при этом заметно ниже.

## MCP и тесты — разные вещи

MCP-сервер нужен агентам для интерактивной проверки. e2e-тесты, которые пишет [qa-engineer](agents/qa-engineer.md), используют пакет `@playwright/test` в самом проекте и запускаются через `make check` и при деплое (`@smoke`).

## Проверка

`/mcp` в сессии: сервер `playwright` должен быть подключён.
